# 绝命毒师 · 回顾 | Breaking Bad Tribute

一个面向粉丝的《绝命毒师》中文回顾网页：复古胶片暖色调（深棕 / 琥珀 / 铁锈 / 奶油），Hero 区三层跑马灯，全屏动态胶片颗粒与暗角，致敬 2008—2013 的阿尔伯克基往事。

## 板块

- **Hero**——Br/Ba 元素周期表方块 + 三层无限跑马灯（悬停暂停）
- **五年编年**——五季交错时间线
- **人物志**——六张做旧照片卡（沃尔特 / 杰西 / 索尔 / 古斯 / 迈克 / 汉克）
- **名场面包厢**——胶片齿孔边框的六帧名场面
- **尘埃落定之后**——剧集数据与衍生作品（《风骚律师》《续命之徒》）

## 本地运行

```bash
npm install
npm run dev
```

## 构建

```bash
npm run build   # 产物在 dist/
```

## 技术栈

React 19 · TypeScript · Vite · Tailwind CSS
